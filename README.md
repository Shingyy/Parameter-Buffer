# Parameter Buffer — VHDL

## Overview
I designed, simulated, and synthesized a Parameter Buffer in VHDL using Vivado. Its goal is to fetch neural network parameters (weights and biases) from Block RAM to their designated MAC units for computation.

## Architecture
The Parameter Buffer consists of two main components:
- A parameterized Demultiplexer (K-to-2^K decoder)
- An array of buffer registers

The selector of the DEMUX specifies the unique address of the buffer register where each parameter will be temporarily stored before computation. The output of each buffer register is connected to its corresponding MAC unit.

## Control Unit Integration
The Parameter Buffer is also designed to receive signals from a Control Unit, which I will soon develop for proper operational control.

## Scalability
Since this design is fully parameterized, the Parameter Buffer for 8, 16, and 32 MAC units can be generated by simply changing the `K` parameter.

| K | MAC Units |
|---|-----------|
| 3 | 8         |
| 4 | 16        |
| 5 | 32        |

## Tools
